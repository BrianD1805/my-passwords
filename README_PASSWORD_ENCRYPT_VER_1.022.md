# Password-Encrypt Ver-1.022 — Vault Home Recovery Simplification

- Simplified the locked Vault Home recovery area to one **Vault access & recovery** link.
- Shortened the master-password message to: **Your master password protects your encrypted vault. Keep it safe.**
- The recovery popup presents three choices: Clear local vault, Recover account access, and Use Emergency Backup Code.
- Selecting a choice first opens concise information for that action before continuing.
- Clear local vault still uses the existing safety confirmation so pending/local-only data warnings are preserved.
- Existing Settings recovery tools, account recovery, Emergency Backup Codes and security behaviour are unchanged.
- No Supabase SQL is required for Ver-1.022.
