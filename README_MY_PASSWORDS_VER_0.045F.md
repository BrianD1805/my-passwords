# My Passwords Ver-0.045F — More Fixes UX & Edits

## Changes

- Removed the separate Offline/Backup details panel from the vault home screen.
- Added an integrated status-detail icon on the right side of the Vault Status panel. It opens the appropriate explanation popup for offline, backup pending, verification, conflict, local-only, syncing and unchecked states.
- Added a green completion tick in the same position when the vault is Up to date.
- Replaced the popup blue top trim with a thicker dark-green accent that fades in from the top-left, wraps around the top-right corner and fades down approximately halfway along the right edge.
- Added three pixels of extra breathing room between custom-dropdown choices and their scrollbar.
- Reduced the Suggest password icon, text size and padding, removed bold text and prevented the blue tap/press highlight.
