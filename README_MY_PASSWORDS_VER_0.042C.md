# My Passwords Ver-0.042C

## Admin UX fixes and refinements

- Admin customer rows display the full saved email address and mobile number.
- Subscription Plans no longer render an empty placeholder plan panel.
- Added Active and Hidden plan filters.
- Active shows plans that are both active and published.
- Hidden shows hidden, unpublished, inactive and other non-public plans.
- The Add plan button remains the only way to open a new blank plan editor.
- No Supabase SQL changes are required.
