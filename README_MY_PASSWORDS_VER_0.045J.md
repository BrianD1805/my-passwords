# My Passwords Ver-0.045J — Popup Top Edge Smoothing Refinement

This corrective patch refines the green popup top edge requested after Ver-0.045I.

All supported popups now use:

- one smooth rounded green edge across the top;
- a natural wrap around both top corners;
- a short, subtle fade down the left and right sides;
- no full green side border;
- the existing faint neutral outer border beneath the accent.

No popup sizing, sticky header/footer, scrolling, vault, sync, subscription or encryption logic was changed.
