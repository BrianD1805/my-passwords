# My Passwords Ver-0.045

## Colour Makeover

Ver-0.045 applies one consistent visual language across the public landing page, Vault, Settings, popups, offline/startup views and the single-site Admin.

### Approved palette

- Primary Blue: `#336699`
- Background Warm Grey: `#F7F5F2`
- Cards and Panels White: `#FFFFFF`
- Primary Text and Icons Soft Black: `#2A2A2A`
- Secondary Text Grey: `#66635F`
- Success / Up to Date Soft Green: `#63A96D`
- Warning / Pending Soft Amber: `#D6A247`
- Error / Delete Soft Red: `#C96A6A`

### Brand image

The supplied lock-and-shield PNG is copied unchanged to:

`public/images/password-encrypt-brand.png`

It is displayed with `object-fit: contain` so the complete square image remains visible without cropping. It is used in the startup splash, Vault login, public header and Admin branding.

The existing browser favicon and PWA manifest icon remain unchanged in this build.
