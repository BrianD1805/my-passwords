# My Passwords Ver-0.042H

## Vault Orange Accent Refinement

This patch adds a restrained orange accent to the private vault while preserving blue as the main security colour.

### Changes
- Added a thin orange top edge and orange focus treatment to the vault login card.
- Changed the primary Unlock Vault and Create Vault actions to solid orange.
- Added an orange accent to the secure-device key icon.
- Changed selected Vault, Settings and Help navigation states to orange.
- Changed the selected folder chip and home-folder indicator to orange.
- Changed the floating Add Item action to orange.
- Changed the Save Item and Create Folder primary actions to orange.
- Preserved green for safe/success, red for errors and yellow for warnings.

### Version alignment
- Visible version: My Passwords Ver-0.042H
- Package version: 0.0.42-h
- Service-worker cache: my-passwords-v0.042H
- Netlify Functions version: My Passwords Ver-0.042H

### Database
No Supabase SQL is required.
