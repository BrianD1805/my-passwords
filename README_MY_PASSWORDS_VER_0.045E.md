# My Passwords Ver-0.045E — More Fixes UX & Edits

## Changes

- Polished the home search field focus state so the highlighted border and inner edge stay clean and even on both sides.
- Updated popup top highlight styling so the blue accent starts after the left curve and wraps around the top-right corner.
- Refined the shared custom dropdown so its scrolling area sits inside the popup/menu and the scrollbar no longer runs hard against the edges.
- Expanded the subscription change section content width and reduced excessive inner safe padding on mobile.
- Improved disabled primary button styling so greyed-out subscription action buttons remain clearly readable.
- Added extra breathing room after the green lifecycle line inside the Subscription active panel.
- Fixed the red Backup Pending vault-status icon treatment so the icon remains clearly visible.
- Replaced the large disruptive backup/offline warning block on the vault home screen with a compact note control; the full message now opens only when the note is selected.
- Changed the Add Item secret entry to a visually concealed non-password field with password-manager blocking attributes so Google does not offer its own strong-password sheet.
- Added an in-app “Suggest” strong-password helper that fills the password field with a mixed upper/lowercase, number and symbol password.
