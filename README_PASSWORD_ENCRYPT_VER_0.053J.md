# Password-Encrypt Ver-0.053J

## Favicon, PWA splash and sharing artwork

Ver-0.053J replaces the legacy favicon/PWA icon artwork with the user-supplied Password-Encrypt lock-and-shield image.

Included:
- browser favicon `.ico`, 16px and 32px PNG variants
- Apple touch icon
- 192px and 512px PWA icons
- separate maskable 512px PWA icon
- circular splash/startup icon using the same uploaded artwork
- legacy `/icons/icon.svg` compatibility asset updated to the same artwork
- Open Graph / social sharing image generated from the supplied icon artwork
- static Open Graph and Twitter sharing metadata in `index.html`
- Ver-0.053J service-worker cache refresh and asset precaching

The normal in-app Password-Encrypt branding remains unchanged. Only favicon/install/splash/share artwork is replaced.

No Supabase SQL or new Netlify environment variables are required.
