# Password-Encrypt Ver-1.011.01 — Onboarding Flow UX Fixes

- Desktop onboarding card footprint reduced by roughly 10% with viewport-safe maximum height.
- Onboarding input text enlarged on desktop and mobile.
- Progress bar redesigned with inset spacing, rounded track and premium gradient treatment.
- Mobile number country-code divider removed from the onboarding field.
- Push activation during first-time setup is now an explicit gate: the install step does not proceed until the customer chooses an action in the push prompt.
- Settings → Account and device now includes Install Password-Encrypt so installation can be retried later.
- Welcome emails no longer instruct a fully onboarded customer to create a master password.
- No database migration or new environment variable is required.
